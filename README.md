# AP Invoice Review Workspace

Shared workspace for the FY2026 Q4 accounts payable invoice review.

- `master/vendor_registry.csv` - approved vendor master
- `history/payment_history.csv` - previously paid invoices
- `policy/ap_policy.md` - review policy and rule codes
- `invoices/` - invoice documents for the current review cycle
- `reports/` - review deliverables
